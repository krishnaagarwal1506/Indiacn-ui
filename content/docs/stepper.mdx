## Introduction

The Stepper component displays progress through a sequence of steps. Useful for multi-step forms, registration flows, and order tracking.

## Installation

<ComponentSource
  collapsible={false}
  code={`import { Stepper, Step } from '@/components/ui/stepper';`}
/>

## Usage

```tsx
<Stepper activeStep={1}>
  <Step step={0} title="First" />
  <Step step={1} title="Second" />
  <Step step={2} title="Third" />
</Stepper>
```

## API Reference

### Stepper

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `activeStep` | `number` | `0` | Current active step (zero-indexed) |
| `orientation` | `horizontal \| vertical` | `horizontal` | Layout direction |

### Step

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `step` | `number` | — | Step index (zero-indexed) |
| `title` | `string` | — | Step title |
| `description` | `string` | — | Step description |
