## Introduction

Separators visually divide content into clear sections. They support horizontal and vertical orientations and are accessible by default (built on Radix UI's Separator primitive).

## Installation

<ComponentSource
  collapsible={false}
  code={`import { Separator } from '@/components/ui/separator';`}
/>

## Usage

<ComponentSource
  collapsible={false}
  code={`<Separator />
<Separator orientation="vertical" className="h-6" />`}
/>

## API Reference

### Separator

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Direction of the separator line |
| `decorative` | `boolean` | `true` | When `true`, the element is hidden from assistive tech |
| `className` | `string` | — | Extra Tailwind classes |
