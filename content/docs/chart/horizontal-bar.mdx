## Introduction

Set `indexAxis: "y"` and the bars run horizontally. Nothing else changes.

All chart types share one component. Installation, the palette, and the reason every chart ships with a screen-reader data table are on the [Charts](/docs/chart) page.

## Example

<ComponentPreview name='ChartHorizontalBar' />

## When to use it

Use it when category names are too long to sit under vertical bars, or when the point is a ranking — a reader scans a vertical list faster than a horizontal one.
