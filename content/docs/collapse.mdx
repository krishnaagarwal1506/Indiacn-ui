## Introduction

Collapse toggles the visibility of content sections with a smooth height animation. Built on Radix UI Collapsible for accessibility.

## Installation

<ComponentSource
  collapsible={false}
  code={`import { Collapse, CollapseTrigger, CollapseContent } from '@/components/ui/collapse';`}
/>

## Usage

```tsx
<Collapse>
  <CollapseTrigger asChild>
    <Button>Toggle</Button>
  </CollapseTrigger>
  <CollapseContent>
    <p>Collapsible content here.</p>
  </CollapseContent>
</Collapse>
```
