## Introduction

The Search component provides a styled search input with a leading search icon, clear button, and multiple size variants.

## Installation

<ComponentSource collapsible={false} code={`import { Search } from '@/components/ui/search';`} />

## Usage

<ComponentSource
  collapsible={false}
  code={`<Search placeholder="Search..." value={value} onChange={handleChange} onClear={handleClear} />`}
/>
