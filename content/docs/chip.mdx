## Introduction

Chips are compact elements used to represent inputs, attributes, or actions. They support icons, avatars, dismissible behavior, and multiple visual styles.

## Installation

<ComponentSource
  collapsible={false}
  code={`import { Chip } from '@/components/ui/chip';`}
/>

## Usage

```tsx
<Chip>Label</Chip>
```

## API Reference

### Chip

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `theme` | `primary \| secondary \| success \| danger \| warning` | `primary` | Color theme |
| `variant` | `filled \| outlined \| tonal` | `outlined` | Visual style |
| `size` | `sm \| md \| lg` | `md` | Chip size |
| `icon` | `ReactNode` | — | Leading icon |
| `avatar` | `ReactNode` | — | Avatar element |
| `onDismiss` | `() => void` | — | Dismiss callback, shows close button |
| `selected` | `boolean` | — | Selected state |
| `disabled` | `boolean` | — | Disabled state |
